# ❤️ FLAMES Calculator

A fun, interactive web-based implementation of the classic childhood FLAMES game (Friends, Lovers, Affection, Marriage, Enemies, Siblings) used to determine relationships based on name algorithms.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3

## 🌟 Features
* Simple, nostalgic web user interface.
* Lightweight structure with zero external dependencies.
* Responsive input forms for seamless access across mobile and desktop devices.
